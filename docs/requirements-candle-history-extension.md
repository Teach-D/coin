# 요구사항 명세서 — 캔들 차트 과거 데이터 확장

## 1. 개요

- **기능 목적**: 업비트 REST API에서 봉 타입별 최적화된 pages 수와 요청 간 딜레이를 적용해, 차트에서 더 넓은 과거 데이터 범위를 안정적으로 표시한다.
- **핵심 사용자**: 시스템 (백엔드 API 호출 로직), USER (차트 조회)
- **범위**
  - In Scope: 봉 타입별 pages 수 조정, 업비트 API 연속 요청 간 딜레이 삽입, 캐시 TTL 유지
  - Out of Scope: 업비트 인증 키 사용(유료 rate limit 상향), 무한 스크롤 방식의 동적 페이지 로딩, DB 저장 방식 캔들 캐시

## 3. 비즈니스 규칙

1. **BR-01** 봉 타입별 pages 상한
   - 조건: 항상 적용
   - 내용: 각 봉 타입별 최대 pages는 아래 표를 따른다. pages를 초과하는 요청은 서버가 상한으로 클램핑한다.

   | 봉 (minutes) | 현재 pages | 변경 후 pages | 커버 범위 |
   |------------|-----------|-------------|---------|
   | 1분 | 10 | 20 | 약 2.8일 |
   | 3분 | 10 | 15 | 약 6.3일 |
   | 5분 | 5 | 10 | 약 7일 |
   | 15분 | 5 | 8 | 약 16.7일 |
   | 60분 | 10 | 10 | 약 83일 (유지) |
   | 240분 | 10 | 10 | 약 11개월 (유지) |

2. **BR-02** 연속 API 요청 간 딜레이
   - 조건: pages > 1인 경우, 각 페이지 요청 사이에 딜레이를 삽입한다.
   - 내용: 100ms 고정 딜레이. 업비트 비인증 rate limit(분당 600 req)의 안전 마진을 확보한다.
   - 근거: pages=20 × 100ms = 2초 지연 추가. 사용자 체감 로딩은 skeleton UI로 보정한다.

3. **BR-03** 캐시 TTL — 기존 정책 유지
   - 조건: 항상 적용
   - 내용: 캐시 TTL = `unit × 60 × 1000` ms (1분봉 = 60초, 240분봉 = 240분). pages 증가로 캐시 키가 변경되므로 기존 캐시는 자연 만료된다.

4. **BR-04** rate limit 재시도 로직 — 기존 정책 유지
   - 조건: 업비트 API가 null(rate limit 초과)을 반환한 경우
   - 내용: [500ms, 1000ms] 딜레이 후 최대 2회 재시도. 최종 실패 시 빈 배열 반환.

## 5. 주요 시나리오

### Happy Path

1. 사용자가 CoinDetailPage에서 봉 타입 탭을 선택한다.
2. 프론트엔드가 `GET /api/market/{ticker}/candles?unit={unit}&count=200&pages={N}` 요청을 보낸다.
3. 백엔드는 업비트 API를 순차적으로 N번 호출하며, 각 호출 사이에 100ms 딜레이를 삽입한다.
4. 수집한 캔들 데이터를 병합해 응답한다.
5. 프론트엔드는 과거 데이터를 차트에 렌더링한다.

### 예외 시나리오

| 시나리오 | 처리 방식 |
|----------|-----------|
| 업비트 rate limit 초과 (429) | BR-04: 500ms → 1000ms 재시도 2회 후 실패 시 빈 배열 |
| 네트워크 오류 | `.on('error')` 핸들러에서 빈 배열 반환, 차트는 수신된 부분만 표시 |
| 동일 요청 동시 발생 | 기존 pendingCandles 맵으로 중복 요청 차단 (현행 유지) |

## 6. 비기능 요구사항

- **성능**: pages=20일 때 최대 응답 시간 약 4~5초 (20회 × 100ms 딜레이 + 네트워크). skeleton UI로 사용자 체감 보정.
- **동시성**: 해당 없음 (사용자별 독립 읽기 요청)
- **Redis 캐시**: 해당 없음 (현재 서버 인메모리 캐시 사용, 변경 없음)
- **외부 연동**: 업비트 REST API `/v1/candles/minutes/{unit}` — 비인증, 분당 600 req 제한
